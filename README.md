# BLSPI API

Backend API for the BLSPI blockchain token project and its connected application ecosystem.

## Project Overview

BLSPI is the proposed token for the BLSPI ecosystem, including BLSPIMarketplace and supported games.

This repository contains the backend source code for API development, token preparation, reward management, and future blockchain integration.

## Current Features

- Express.js backend server
- API health and status endpoints
- Initial token development structure
- Preparation for reward and transaction management

## Technology Stack

- Node.js
- Express.js
- JavaScript
- REST API

## API Endpoints

### GET /

Returns the API project information and server status.

### GET /api/status

Returns the backend status and current token development status.

## Token Status

BLSPI token minting has not yet been completed.

Blockchain integration, wallet configuration, token issuance, and transaction verification must be implemented and verified before production use.

## Security

- Never expose private keys or wallet seed phrases.
- Store sensitive credentials in secure server-side secrets.
- Validate and authorize requests before processing rewards or transactions.
- Verify blockchain transactions before crediting confirmed on-chain activity.

## Development Status

Backend development and blockchain integration preparation are in progress.
